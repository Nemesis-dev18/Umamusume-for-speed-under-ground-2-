3. TILLÄGG TILL MANUALEN

************************************************************


STÖD FÖR GRAFIKKORT
===================

Även om Direct3D stöds gäller detta stöd officiellt endast vissa 3D-kort.
Följande ledande D3D-chipsets stöds.

ATI Radeon 7500 eller nyare
NVIDIA GeForce2 eller nyare

Även om Direct3D stöder fler 3D-kort än de som räknas upp här, kan funktionen i
NEED FOR SPEED UNDERGROUND 2 inte förutses om annat kort används. I extrema fall
kan användning av Direct3D-kort som inte stöds officiellt leda till en instabil
datormiljö.

STÖD FÖR LJUDKORT
=================

NEED FOR SPEED UNDERGROUND 2 stöder DirectSound. Om ditt ljudkort inte stöder
DirectSound kan du märka av ryckigt eller ofullständigt ljud, eller ljud som
klipper. Om din ljudkortsdrivrutin inte stöder DirectSound rekommenderar vi att
du uppdaterar med nya drivrutiner från ljudkorttillverkarens hemsida.


CD-ROM/DVD-LÄSARE
=================
NEED FOR SPEED UNDERGROUND 2 kräver en läsare som klarar minst åtta gångers
hastighet (8x). Skiva 2 måste sitta i läsaren när du startar spelet. Om din
dator har fler än en läsare ska du se till att skivan sitter i samma enhet som
du installerade spelet från.


STANDARDINSTÄLLNINGAR FÖR GRAFIK
================================
Första gången NEED FOR SPEED UNDERGROUND 2 körs utförs en systemkontroll och
standardnivåerna ställs in för de olika grafikinställningarna. De här
standardnivåerna ställs in för att ge dig bästa möjliga spelmiljö baserat på den
maskinvara som identifieras i ditt system.

Inställningarna kan ställas in via menyn Bildskärm i Alternativmenyn. Under
Bildskärmsalternativ, välj Anpassa bildskärmsinställningar.

Upplösning: Använd pilarna för att öka eller minska spelupplösningen. Om du ökar
spelupplösningen kan det försämra systemets prestanda.

Detaljnivå: Använd pilarna bredvid detaljlisten för att öka eller minska den
generella grafiknivån. Om du höjer värdet ser spelet bättre ut rent grafiskt men
systemets prestanda kan försämras.

Anpassa bildskärmsinställningar: Anpassa individuella grafikinställningar (se
nedan).

Standardinställningar: Återställ dina grafikinställningar till de som är
standard för din maskinvarukonfiguration.

Under menyn Anpassa bildskärmsinställningar kan du ställa in följande
individuella inställningar för att anpassa spelets grafik- och spelprestanda. Om
du aktiverar alla inställningar kan det försämra systemets prestanda.

Uppdateringsfrekvens för bilreflektioner: Öka eller minska hur snabbt reflexer
på bilen uppdateras.

Detaljnivå på bilreflektioner: Om du väljer ett högt värde ökas detaljnivån på
reflexer som visas på bilen.

Bilskugga: Öka/minska bilskuggornas förekomst. Minskade skuggor kan förbättra
systemets prestanda.

Strålkastare: Välj om strålkastarna ska vara av eller på.

Detaljnivå på bilgeometri: Ett högt värde öka detaljnivån på bilens geometri.

Publik: Välj om animerade figurer i publiken ska visas eller inte.

Detaljnivå på världen: Öka eller minska hur mycket detaljer som visas i den
omgivande spelvärlden. En minskning kan förbättra systemets prestanda.

Detaljnivå på vägreflektioner: Öka eller minska detaljnivån på synliga
vägreflektioner.

Ljusspår: Välj om de ljusspår som skapas när du kör med strålkastarna på ska
visas eller inte.

Ljusglöd: Välj om glöd i ljuskällor ska visas eller inte.

Partikelsystem: Välj om partikeleffekter ska visas eller inte.

Rörelseoskärpa: Välj om rörelseoskärpa ska visas eller inte.

Dimma: Välj om dimma ska visas eller inte.

Fältdjup: Välj inställning för kameror som visas i start- och stoppsekvensen av
ett race.

Kantutjämning för fullskärm: Dra i skjutlisterna för att öka/minska
pixelutjämningen.

Toning: När vald till På ändras färgerna på skärmen efter vädret.

Horisontdimma: Välj om molnslöjor över byggnader och på himlen ska visas eller
inte.

Extra glans: När vald till På ökar ljusstyrkan på ljusa områden av spelet.

Förbättrad kontrast: Mörka fält blir ännu mörkare och ljusa fält ljusare.

Regn: Välj om regnstänk ska visas eller inte.

Texturfiltrering: Justera skjutlisterna för att öka/minska texturernas
kvalitet.

Vertikal synkronisering: Uppdaterar skärmen baserat på din bildskärms uppdateringsfrekvens.


På grund av begränsningar hos maskinvaran är det inte säkert att alla
inställningar finns tillgängliga för alla grafikkort.

FÖRARPROFIL OCH SPARA/LADDA
===========================

Om du har huvudmenyn öppen och vill skapa en ny förarprofil, välj Skapa från
Profilhanteringsmenyn.

När du startar med en ny förarprofil finns inga spelframsteg, som upplåsta
bilar/delar eller karriärframsteg, sparade. (Du kan alltid logga in under din

Profilhantering och välja Spara.

OBS!

spelomgång sparas dina framsteg i karriärläget, antalet bilar,
biluppgraderingar, upplåsta banor och eventuella modifieringar du gjort av dina
bilar.

Sparmappen hittar du i:
\Documents and Settings\Användarnamn\Lokala inställningar\Application Data\NFS
Underground 2

Ersätt ”Användarnamn” ovan med ditt verkliga ”Användarnamn”.

SPELA UPP AUTOMATISKT
=====================
Om du sätter i spelskivan i din läsare och sedan omedelbart kör spelet, antingen
från Startmenyn eller genom att dubbelklicka på spelets skrivbordsikon, kan det
orsaka en konflikt med funktionen Spela upp automatiskt. Enklaste sättet att
undvika den här potentiella konflikten är att alltid vänta en stund efter att du
lagt i spelskivan och på så sätt låta funktionen ”Spela upp automatiskt” starta
upp spelet.


MATA UT SPELSKIVAN
==================
Ta aldrig ut spelskivan när spelet körs. Om du gör det kan du få allvarliga
problem med spelet eller så kan spelet krascha.


SNABB ANVÄNDARVÄXLING
=====================
Det går inte att köra två versioner av spelet med två olika Windowskonton och
växla mellan dem med Windows-tangenten + L.


DRIVRUTINER
===========
Vi rekommenderar att du laddar ned och installerar de senaste versionerna av
alla grafik- och ljuddrivrutiner. Du hittar normalt drivrutinerna på
korttillverkarens hemsida på internet. Kom också ihåg att även drivrutinerna
till kortets chipset kan behöva uppdateras.

Om du får problem med en instabil datormiljö ska du se till att moderkortets
drivrutiner (AGP, miniport) är uppdaterade. Mer information hittar du på
moderkorttillverkarens hemsida.

PROBLEM MED VIDEO OCH GRAFIK
============================
Om du får problem med grafikkortets standardinställningar, prova att sänka några
av inställningarna eller minska spelets upplösning.

Det kan hämtas på:

Grafikkort: Vilka grafikinställningar och funktioner som finns tillgängiga i
spelet beror på vilket grafikkort som används. De inställningar som inte stöds
av ditt grafikkort gråskuggas i Alternativmenyn för att förhindra

NVIDIA-kort: Alla NVIDIA-kort som stöds testades med ForceWares drivrutin

ATI-kort: Alla ATI-kort som stöds testades med Catalysts drivrutin version 4.10

Om det skulle uppstå problem vid start av spelet, dubbelklicka på SafeMode.bat i
installationskatalogen. Detta startar NEED FOR SPEED UNDERGROUND 2 med den
lägsta grafikinställningsnivån.

PROGRAM SOM KÖRS I BAKGRUNDEN
=============================
Kör helst inga program i bakgrunden.

Program som startar automatiskt kan orsaka att NEED FOR SPEED UNDERGROUND 2
tappar kontrollen över skärm/tangentbord och leda till en instabil datormiljö.
Innan du kör NEED FOR SPEED UNDERGROUND 2 rekommenderar vi starkt att du stänger
ned eller inaktiverar alla övriga program, samt applikationer som körs
automatiskt vid bestämda klockslag. Det här inkluderar men är inte begränsat
till:
	- Windows Systemagent
  	- Windows Schemaläggare
	- Windows Diskrensningsverktyg

Dessutom kan meddelande- och dialogrutor från andra program eller Windows självt
medföra att NEED FOR SPEED UNDERGROUND 2 tappar kontrollen över skärm/
tangentbord och leda till en instabil datormiljö. Innan du startar NEED FOR
SPEED UNDERGROUND 2 rekommenderar vi starkt att du stänger ned alla övriga
program. Det här inkluderar men är inte begränsat till:

  	- E-postprogram
	- Kalender-, mötes- eller kontaktprogram
	- Nätverks- eller chattprogram
	- Automatiska uppdateringar av antivirusprogram

Dessutom kan anslutningar till/från icke-dedikerade servrar stoppas när program
körs i bakgrunden eller när skärmsläckare startar. Vi rekommenderar att du
stänger ned alla andra program (inklusive antivirusprogram) och kör NEED FOR
SPEED UNDERGROUND 2 som enda program när så är möjligt.


STRÖMFÖRSÖRJNING VÄNTE-/VILOLÄGE
================================
Datorer (främst bärbara datorer) som automatiskt går in i vänte- eller viloläge
kan orsaka att NEED FOR SPEED UNDERGROUND 2 tappar kontrollen över skärm/
tangentbord och leda till en instabil datormiljö. Vi rekommenderar därför starkt
att du stänger av dessa funktioner innan du startar NEED FOR SPEED UNDERGROUND
2.

ALT+TAB-FUNKTIONALITET
======================
ALT+TAB tar dig ur NEED FOR SPEED UNDERGROUND 2, men spelet pausar inte
automatiskt. Om du vill hoppa ur spelet, pausa det manuellt innan du fortsätter.

5. ONLINE-SPEL

************************************************************

För att undvika dåliga prestanda under online-spel bör du se till att stänga
ned alla typer av fildelning, strömmande audio och chattprogram innan du börjar.
Dessa typer av applikationer kan lägga beslag på en stor del av bandbredden
vilket kan orsaka tidsfördröjningar eller andra oönskade effekter.

NEED FOR SPEED UNDERGROUND 2 använder följande TCP- och UDP-portar för
online-spel:

TCP-portar: 80, 13505, 20920-20929, 20970-20979
UDP-portar: 3658, 3659

Se dokumentationen till din router eller personliga brandvägg för information om
hur du konfigurerar och öppnar dessa portar för trafik. Om du försöker spela via
ett företags uppkoppling, kontakta din nätverksadministratör.

OBS! NEED FOR SPEED UNDERGROUND 2 stöder endast bredbandsuppkoppling.

När du loggar in för online-spel loggar du in på EA.com:s server. Om du redan har
ett konto kan du använda det, annars måste du skapa ett nytt.

Skapa ett EA-konto: Du måste ha ett EA-konto för att kunna spela online. På
inloggningsmenyn väljer du Skapa nytt EA-konto. Olika menyer där du anger
kontoinformation och väljer användarnamn/personlighet visas.

OBS! Du kan inte använda ditt befintliga EA-konto om det innehåller mellanslag.
Detta beror på en begränsning i själva spelet.

Du kan ha upp till fyra online-personligheter hos EA. Du kan ta bort en
personlighet för att skapa en ny.

OBS! Personligheter är en del av ditt EA-konto och används för alla EA-titlar du
spelar med online. Om du raderar en personlighet som använts till ett annat
EA-spel raderas även all associerad statistik/belöningar du vunnit med den
personligheten.

Starta ett nytt spel online: När du har loggat in ska du välja bil. Alla
bilar/delar och banor du låst upp för läget Ensam spelare är tillgängliga även
för online-spel.

Online-huvudmenyn
================

Online-lobby: Gå med i ett befintligt race, skapa ett nytt online-race eller
använd lobbyfiltret. Alla rankade race räknas mot din online-rankning. Arbeta dig
genom tio rankningslager per speltyp för att uppnå elitstatus. Ej rankade race
påverkar inte din rankning. Alla bilar kan användas i race som inte rankas.

Välj bil: Välj bil för nästa race.

Nyheter: Läs de senaste nyheterna om NEED FOR SPEED UNDERGROUND 2 eller studera
villkoren för medlemskap.

Rankningar: Rankningstavlorna används för att hålla koll på dina härjningar på
nätet och är uppdelade i tre specifika undergrupper:

Personlig rankning: Här hittar du din personliga statistik, inklusive bästa
tider, längsta sladd, etc.

Övergripande rankningar: Här visas de poäng du tjänat i alla rankade race. Ju
mer poäng du tjänar, desto högre placerar du dig på ledartavlan. När du når en
ny rankningsnivå, hamnar du längst ned i den nya ledartavlan. Du kan endast visa
rankningar för spelare inom din egen rankningsnivå för varje speltyp.

Poängledare för månaden: Det är här du hittar de bästa spelarna. Titta in här
för att se vem som har tjänat ihop flest rankningspoäng under aktuell eller

Alternativ: Ändra spelinställningar.

EA Messenger: Hitta dina vänner online eller stifta nya bekantskaper.
Du öppnar EA Messenger genom att klicka på knappen EA Messenger. För att växla
mellan vänlistor, vänförfrågningar och blockerade spelare använder du
piltangenterna. Klicka på en spelares namn i din EA Messenger för att skicka ett
meddelande, en utmaning eller en vänförfrågan. Du kan också blockera spelare
från EA Messenger liksom erbjuda dem feedback.

Online-lobbyn
============

Det är i online-lobbyn alla skapade matcher visas. Välj en match i listan för att gå
med i det.

Använd filtreringsalternativen för att välja vilken typ av match och
spelalternativ du är intresserad av. Då visas endast de matcher som uppfyller dina
filtreringskategorier.

Välj Skapa match för att själv stå som värd och välj sedan vilken bana du vill
köra på och vilka spelalternativ som ska gälla.

Spellistan fluktuerar hela tiden eftersom nya matcher skapas och spelare går med i
dem. För en aktuell lista klickar du på Uppdatera.

Vissa matcher kan vara skapade med inställningen Jämnt matchade bilar.
Dessa matcher kontrollerar om den bil du valt är jämbördig med de andra spelarnas
bilar. Om din bil är för vass eller inte håller måttet får du inte vara med i
den spelsessionen.

OBS! I rankade matcher väljs automatiskt den rankade bilen för den
speltypen. Spelarna måste förbereda en rankad bil för varje rankad speltyp i
menyn Anpassa under menyn Välj bil för online-läget. Rankade standardbilar finns
och dessa bilar kan bytas in mot andra upplåsta bilar genom att du väljer
Anpassa när en rankad bil är markerad då du öppnar bilbytesmenyn.

Matchrumsalternativ
==================

Klar/Ej klar:

I ett matchrum har alla spelare en liten röd ikon till vänster om sitt namn.
Dessa ikoner representerar spelarens status. När du är redo att starta racet,
välj knappen Klar. Detta ändrar ikonen från röd till grön, vilket signalerar att
du är redo att gå med i racet. Det enda alternativ du har att välja på i detta
läge är att chatta. Inga alternativ för värd/klient finns tillgängliga. Om du
vill komma åt värd- eller klientalternativ eller lämna rummet när du står har
Klar-status, måste du välja Avbryt. Detta ändrar ikonen till röd och signalerar
till de andra spelarna att du inte längre är redo att köra.

En värd behöver inte signalera sin status då de alltid visas som redo att köra.
Värden har istället knappen Starta race. Knappen Starta race kan endast väljas
då tillräckligt många spelare är redo att köra. Ej rankade matcher kräver minst
2 färdiga spelare, medan rankade matcher kräver 3 färdiga spelare. Om värden
bestämmer sig för att starta racet även då alla spelare inte valt Klar, påbörjas
en nedräkning på 10 sekunder. Om spelare efter nedräkningen ännu inte valt Klar,
tas de bort från spelsessionen och de spelare som är klara kör igång.

Klient/Värdalternativ:

I både andra spelares och ditt eget matchrum har du tillgång till några
extraalternativ. Välj ett spelarnamn i matchrummet för att visa en lista över
tillgängliga alternativ.

Visa bankarta – Visar vald bana för kommande race.

Visa bil – Visar vilken bil vald förare kommer att köra i detta race.

Skicka privatmeddelande – Gör det möjligt för dig att skicka ett privat
meddelande till vald spelare.

Feedback – Skickar klagomål om vald spelare och även chattloggen från matchrummet
till EA:s kundsupport där den kommer att läsas igenom. Missbruk av denna
funktion kan medföra avstängning och/eller avslut av ditt EA-konto, vilket
stoppar dig från att köra fler onlinerace i NEED FOR SPEED UNDERGROUND 2
och/eller andra spel för EA-produkter.

Värden har ett ytterligare alternativ kallat Sparka ut spelare, vilket kastar ut
spelaren från matchrummet.

Chatt under match/Avkänning av fusk och diskvalificering
=======================================================

För rankade matcher aktiveras ett system för upptäckandet av fusk som övervakar
racet. Alla försök att mixtra med bildata, bilfysik eller lustgas upptäcks av
servern och fuskande spelare kommer att flaggas.

Alla spelare som upptäcks fuska eller uppför sig på ett sätt som inte är
förenligt med seriös racing diskvalificeras efter loppet, men kan även tas bort
redan under loppet.

NEED FOR SPEED UNDERGROUND 2 har en avancerad meny kallad Efter racet där alla
resultat godkänns av servern innan de blir officiella.

Beroende på serverbelastning när racet körs kan det ta mellan 5 sekunder till
några minuter innan resultaten godkänns och postas officiellt. När resultatet är
slutgiltigt ändras det från Väntar på slutresultat till Officiella
raceresultat.

Om en spelare diskvalificerats eller kopplats bort under racet, justeras
slutresultatet och utdelade poäng på denna meny.

Spelare som diskvalificeras för många gånger får se sitt namn byta färg i
matchrummen. Detta uppmärksammar andra spelare och de bör därför tänka sig för
innan de tillåter dem i racet.

Namnfärgerna för diskvalifikationer är följande:

Vit: Inga diskvalifikationer – bra spelare att tävla mot.
Gul: Flera diskvalifikationer – för det mesta sköter sig spelaren.
Orange: Spelare som har ett flertal diskvalifikationer och andra spelare bör
tänka sig för innan de spelar.
Röd: Spelaren har mängder med diskvalifikationer och vi rekommenderar att du
inte spelar mot dem.
Lila: Denna spelare har nått ett stadie där vi rekommenderar att du undviker dem
helt och hållet.

EA övervakar regelbundet spelare och serverresultat och om fusk upptäcks agerar
vi omedelbart och fryser kontot för den person som uppenbart försöker att
förstöra spelupplevelsen för andra.

6. LAN-SPEL

************************************************************

Med NEED FOR SPEED UNDERGROUND 2 kan du spela över lokala nätverk (LAN).

Om du vill vara värd för en LAN-server (motsvarande EA-lobbyn) ska du välja LAN
i huvudmenyn och sedan Vara värd för LAN-server. Du uppmanas skriva in ett
namn för LAN-servern.

Därefter flyttas du till LAN-huvudmenyn där du kan öppna alternativ för bilval
eller lobbyn. När du är värd för en LAN-server kommer din dator vara huvuddator
för alla spelare som vill gå med i matchen. I praktiken kommer din dator
att länka samman alla spelare som går med i din match, vilket gör att de
kan starta matcher och rapportera tillbaka till din server när de är klara.

Om du stänger av din dator eller lämnar LAN-läget då andra spelare är anslutna
till din server, kopplas de bort från LAN-läget när de är klara med racet.

För att gå med i ett LAN-race, välj LAN i huvudmenyn och sedan namnet på den
LAN-server du vill ansluta till. Uppge därefter ditt spelarnamn.

I LAN-huvudmenyn är du sedan fri att välja/anpassa bilar, gå in i lobbyn för att
gå med i/skapa match eller justera dina alternativ.

LAN-spelets prestanda varierar beroende på din dators hastighet och mängden
tillgängligt minne. Du kan justera hur mycket tid som ska läggas på att ta hand
om LAN-förfrågningar genom att redigera inställningen LAN_THROTTLE i filen
”server.cfg” i installationskatalogen. Om du ändrar parametern till ett lägre
värde kan spelets prestanda förbättras för vissa datorer.

7. INFORMATION OM SPELKONTROLLER

************************************************************

KONTROLLKONFIGURATIONER
=======================
NEED FOR SPEED UNDERGROUND 2 stöder många populära spelkontroller och andra
spelenheter. Om din enhet inte känns igen eller om du vill ändra den
konfiguration som spelet tilldelat din spelkontroll, öppna Kontroller under
Alternativ i huvudmenyn. Verktygen i den här menyn är användbara för att anpassa
din spelkontroll för optimalt spel.

PROBLEM MED JOYSTICK
====================
Du korrigerar de här problemen genom att konfigurera och kalibrera enheten i
Windows Kontrollpanel. Om problemen kvarstår kopplar du bort enheten från datorn
innan du spelar NEED FOR SPEED UNDERGROUND 2. Se till att du har installerat de
senaste drivrutinerna för enheten.

- Muspekaren rullar automatiskt genom knapparna på menybilderna.
- Din bil gör oregelbundna rörelser som är oavsiktliga (exempelvis att den
svänger hela tiden).
- Vissa rörelser utförs inte när korrekt riktning trycks ned.
- Dåliga svarstider på långsammare maskiner.


INSTÄLLNINGAR FÖR FORCE FEEDBACK
================================
Force Feedback aktiveras inte i menyn Rattkonfiguration innan korrekta,
enhetsspecifika drivrutiner har installerats för spelkontrollen. Windows
standarddrivrutin har inte stöd för Force Feedback-funktionen.


PROBLEM MED TANGENTBORDET
=========================
Du ställer in känslan/känsligheten för styrningen i spelet när du använder
tangentbordet genom att välja Tangentbord i Kontrollpanelen (Start -
Inställningar - Kontrollpanelen). Genom att justera Fördröjning och
Repetitionshastighet kan du justera kontrollerna så att de känns mera analoga
eller digitala beroende på egna önskemål.

Vissa nyare tangentbord tillåter inte kombinationer av två eller flera tangenter
samtidigt. Om du till exempel håller nere både piltangent Upp för att accelerera
och Piltangent vänster för att svänga och tryckt ned ”C” för att byta visning,
kanske inte vyn ändras. Tyvärr beror det här problemet på begränsningar hos
maskinvaran.
