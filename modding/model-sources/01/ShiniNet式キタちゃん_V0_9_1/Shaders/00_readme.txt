DISPLAY LANGUAGE FOR THIS APPLICATION CURRENTLY ONLY COMPATIBLE WITH JAPANESE. SORRY.

■必須ファイル

・AlternativeFull.fx
・AlternativeFull.fxsub
・シェーディングヒントテクスチャ(shading_hint～.pngとして同梱されているもの、もしくは自作)

■概要

色々な機能を詰め込んだシェーダーです。
自分のために、他の平行光源ベースのシェーダーを使わなくてもいいように作っています。
MMMには対応していません。

解説ページ http://ch.nicovideo.jp/LessThanEqual/blomaga/ar1023498

・機能選択式により、無駄な負荷が極力かからない構造。機能を追加した分だけ重くなる構造とも言う。
・自由な明暗の設定
・ハイライト追加、強さ調節
・複数の影色決定方式
　→乗算色指定
　→自己乗算での色決定(self overlayするようなものです)
　　→陰度と乗算しない設定も可
　→影色テクスチャ指定
・モデルのスペキュラ、スフィアのブースト
　→どちらもON/OFFが可能
・複数のスペキュラモデルに対応
　→標準的なスペキュラの他にメカシェーダー互換的なスペキュラが利用可能です
・セルフシャドウ設定
　→MMD標準
　→そぼろさんのAbsoluteShadow(AbsoluteShadowShaderSystem.fx、AbsoluteShadowCommonSystem.fxをこのfxと同じ場所にコピーする必要があります)
　　→full_AS.fxの代わりとして動作します。MMDでAbsoluteShadowが動作している必要があります。
　→そぼろさんのExcellentShadow(ver2で動作を確認しています)
　　→full_ES.fxの代わりとして動作します。MMDでExcellentShadowが動作している必要があります。
　→ExtendShadowのシャドウマップに対応し、full_EX.fxの代わりとして動作します。(半影未対応)
　→「白(影にならない)～50%グレー(通常挙動)～黒(常に影)」を指定するテクスチャが利用可能。
・独自のエッジ描画
　→色トレスエッジ(標準)
　→エッジ色マップ(要エッジ色テクスチャ)
　→エッジ太さマップ(要エッジ太さテクスチャ)
　→AOエッジ(ExcellentShadow2とその付属のExShadowSSAOが両方MMD上で機能していると勝手に有効になります)
・法線マップ(要法線テクスチャ)
・照明の種類選択
　→標準
　→ランバート照明っぽいもの
　→材質の法線を光源に指定%だけ追従させることが可能です。有効にした上で、同梱の「追加モーフ.csv」をPMXEditorでモーフとして「CSVファイルから追加／更新」して制御します。
　→光源と絶対値90度以上の角度をなす面が最も暗い部分になる計算を、180度まで拡張するモードを追加。
・フィルライト
　→視線方向
　→MMD照明とZ軸以外原点対称
・リムライト
・32bit版MMD向けにfxでの異方性フィルタ処理が選択可能。もちろん64bit版で明示して利用することもできます。
・同梱の改造ExcellentShadowにより、MMD標準の光源角度とは別系統の光源角度を任意のモデル(材質)に適用可能。
・テクスチャのαチャンネルを抜いたセルフシャドウの描画。
・αチャンネルに線形補完をかけないテクスチャフィルタ。
・シャドウ、ハイライトそれぞれのカラーに対応したテクスチャ指定。


■設定ツールの使い方

.NETFramework 3.5のランタイムが必要です。

http://www.microsoft.com/ja-jp/download/details.aspx?id=22

多分このあたりでダウンロードできます。(保証はしません)

1.同梱のAlternativeFullFrontend.exeを起動します。
2.「fxファイル」に出力したいfxファイルを指定します。新規でもOKですし、既存のファイルを開いたりウインドウにドラッグ＆ドロップしてもOKです。
3.「シェーディング1」タブでシェーディングヒント用テクスチャを指定します。テキストボックスに画像ファイルをドラッグアンドドロップしてもOKです。
4.各種設定を弄ります。
5.「fx出力」ボタンを押します。
6.作成されたfxファイルをMMDの「MMEffect」→「エフェクトの割当」ウインドウから対象のモデルに適用してください。

・現在「その他」タブの「値が変更されたら自動的に出力する」は動作しません。
・Windows7(64bit)環境で製作していますので、WindowsXpやWindowsVista、Windows8以降では表示がおかしいことがあるかもしれません。
・「その他」タブの「テクスチャファイルを.fxと同じ場所にコピーする」にチェックが入っていない場合、テクスチャファイルは絶対パスで記録されます。そのためここにWindowsのユーザー名が含まれる場合があります。再配布時には注意してください(fxファイル内では相対指定も可能です)。


■同梱エフェクトに関して

[ExcellentShadow]
嘘影が使えるように拡張されているもので、それを使わないときには普通のExcellentShadowをご利用ください。
拡張されているが故に重いのです。

[DropHair]
視線方向からのドロップシャドウ方式のセルフシャドウを実現するためのエフェクトです。
単体ではなんの効果も出ません。
→設定方法は同梱の「使い方.txt」を参照してください。
「セルフシャドウ」タブにて「□2Dドロップシャドウを使う」にチェックを入れて出力したシェーダーで効果を発揮します。


■Tips

[UI]
・テクスチャの設定項目は、テキストボックスの中に画像ファイルをドロップすると設定できます。
・テキストボックス付きのスライダ項目は、テキストボックスに数値を入力して制限値以上を設定することもできます。

[光源方向追従法線]
　法線を元に計算しているスフィアが結構影響を受けます。だいぶ酷いことになる場合も。

　これ単体だけでセルルック的な顔の設定が完結するわけではありません。法線の方向を光源に向けても、セルフシャドウは通常のままだからです。(モデルの顔の法線を正面にしただけで全てが解決しないのと一緒です)
　例えば自分の場合だと、顔の材質を

・セルフシャドウマップ OFF
・セルフシャドウ ON

つまり「セルフシャドウを受けるけど自分のセルフシャドウは作らない」に設定ています。これによって鼻や頬などの嫌な影が顔に落ちるのを防ぐわけです。(前髪の影のために、顔材質には視認できるセルフシャドウが落ちる前提です。)

　とはいえ、このままでは首に頭の影が落ちないことになりますので、そちらの対処を考える必要があります。かにひらせんせーのメルフィのモデルのように、セルフシャドウ作成用材質を設定するのが多分一番簡単です。

　最後に、この機能は光源との向きの関係によってモーフスライダを調節してください。完全逆光で顔だけ光っていてもおかしいと思わないのであればそのままでいいですけども。

[影傾向テクスチャ]
AOのみをグレースケールで焼きこんだテクスチャを用意して、黒～50%グレー(諧調で言うところの0～127)に潰してこれに適用すると、AO系エフェクトなしで似たような効果を得られたりもします。

[ExcellentShadow]
同梱の改造ExcellentShadowは、だいぶ低スペック向けの設定になっています。
品質的に「ｱﾙｪ？」と思った場合はExcellentShadowCommonSystem.fxを編集してください。元のExcellentShadowと同じです。

■既知の問題点

・設定ツールでまともな例外処理をしていません
・fxファイルはシフトJISでの記述になりますが、ファイル(fx、各種テクスチャ)のパスに日本語が含まれている場合MMEに読み込んでも正常に動作しない場合があります。極力日本語を避けてください。現状対処していません。以下駄目そうな文字です。
ソ、Ы、Ⅸ、噂、浬、欺、圭、構、蚕、十、申、曾、箪、貼、能、表、暴、予、禄、兔、喀、媾、彌、拿、杤、歃、濬、畚、秉、綵、臀、藹、觸、軆、鐔、饅、鷭、偆、砡、纊、犾
・ドラッグアンドドロップはfxやテクスチャファイル以外もほおりこめてしまいます。fxに出力していない場合は設定が失われてしまいますので注意してください。
・AbsoluteShadow利用時の影とハイライトの関係があやしい。
